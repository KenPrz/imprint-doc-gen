Roadmap and validation

This release implements the eight requested workstreams and adds these documentation pages. Each adapter has a bounded support contract.

Workstream Delivered
Operations Authenticated metrics, reproducible load runner, verified SQLite backup/restore.
Images Contain/cover/fill, crop, rotation, EXIF orientation and repeated spreadsheet pictures.
Authoring Field inspection, required flags, paragraph/cell diagnostics and PDF preview.
Expressions Locale/time-zone options, number/currency/date formatting, conditional values and array filters.
Advanced Office Notes/comment fields, numbering preservation, spreadsheet multi-row blocks/merges and extra formulas.
Additional formats PPTX, ODT, ODS and ODP adapters with 100 regression cases each.
Document assembly PDF merge/split, text watermarks, numbering, attachments and barcode/QR PNGs.
Distributed deployment PostgreSQL/S3, independent workers, lease fencing and signed durable callbacks.

Feature expansion

The completed feature expansion implements all nine scoped workstreams: CSV/plain text, DOCX numbering restarts, repeated notes/comments, ODS reference rewriting, additional XLSX formula families, passive SVG and inline pictures, literal category charts, worker metrics aggregation and verified offline cluster migration. See contracts and examples and operational instructions.

Future work remains explicit

  • Representative application pilot acceptance, Microsoft Office repair-free opening and approved visual baselines.
  • Workbook-linked chart editing, pivots, threaded comments, tracked changes, style-inherited numbering restarts and broader formula coverage.
  • Cross-sheet ODS references, general SVG/CSS/vector preservation and deeper independent format fixtures.
  • HTML-to-PDF, validated PDF/A or PDF/UA, signatures and specialist formats.
  • Tenant self-service, SSO and billing.

Passing regression suites establishes the documented contracts, not universal Office compatibility.
