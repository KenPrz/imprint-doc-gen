Expanded document features

Text exports, richer Word templates, spreadsheet references, chart data and cluster operations.

CSV and plain text

Use UTF-8 text and the existing {d.path} syntax. The CLI detects .txt and .csv inputs. For the SDK and HTTP service, wrap the source with encodeTextTemplate; this explicit envelope lets stored template versions retain their format.

import { encodeTextTemplate, render } from 'imprint-doc-gen';
const template = encodeTextTemplate('csv',
  'Name,Amount\n{d.rows[i].name},{d.rows[i].amount}\n{d.rows[i+1]},');
const bytes = await render(template, {
  rows: [{name: 'Alex, Jr', amount: 12.5}]
});
// HTTP: send template.toString('base64') as the template property.
// CLI: npm run render -- template.csv data.json output.csv

CSV parses quoted input records and writes RFC 4180 escaping with CRLF separators. Cells starting with whitespace/control characters followed by =, +, -, or @ receive a leading apostrophe, including negative numbers. This deliberately favors safe spreadsheet opening over retaining numeric typing. Text output preserves line breaks. Repeats support one unfiltered array per record/line followed immediately by a standalone increment-marker record/line; nested and multi-record repeats are not supported. Scalar formatters accept locale/timeZone. Limits are 8 MiB and 10,000 repeated records. CSV/TXT do not convert to PDF.

Word lists, notes and inline pictures

Set restartNumbering: true in render options to assign a fresh numbering instance per repeated item. Explicit numId lists restart at 1; existing level formatting is retained. The default preserves numbering. Style-only list numbering is unchanged.

Footnotes, endnotes and classic comments referenced inside repeated rows or blocks receive distinct definitions and reference IDs. Inside a cloned definition, {{note}} or {d.note} reads the current repeated item; use {{../title}} for its parent scope. Definitions outside repeats use the document root. Comment ranges must remain within one repeated region and must use separate paragraphs from footnote/endnote anchors; overlapping annotations misrenders endnote text in LibreOffice 26.2.5.2 and is rejected. Repeated comments and endnotes cannot share one story: LibreOffice can duplicate endnote text even when the native IDs are correct, so this combination is rejected. Threaded comments and bound pictures in repeated notes are also rejected.

To insert a picture without preparing a placeholder, put {{inline:logo:120:60}} in a single Word text run. Width and height are pixels (1–4096); provide attachments.logo and optionally data.logo to select another attachment key. The marker becomes an inline DrawingML picture. A missing attachment is an error. Existing placeholder-image bindings remain available.

Passive SVG

PNG/JPEG attachments now also accept a restricted SVG subset, rasterized to PNG before insertion. Supported geometry includes svg, g, path, rect, circle, ellipse, line, polyline and polygon, with explicit fill/stroke/transform attributes. CSS, scripts, text/fonts, embedded images, foreignObject, references and URL loading are rejected. Output therefore remains portable raster media, not editable vector artwork. Existing size and pixel budgets apply.

Spreadsheet formulas

XLSX adds LEFT, RIGHT, MID, TRIM, INT, MOD, SQRT, POWER, COUNTA and COUNTBLANK. LEFT and RIGHT currently require an explicit character count. Text slicing uses UTF-16 code units. Range evaluation retains the operation budget and error values. The independent LibreOffice comparison suite includes the new families. Negative SQRT returns Excel’s #NUM! (LibreOffice 26.2 uses #VALUE!); the cross-application test checks that case through IFERROR, while a scalar regression checks the Excel error code.

ODS repeats rewrite local bracketed A1 references such as of:=[.A1]*[.B$1] and ranges such as of:=SUM([.A1:.A3]). Dollar-locked rows stay fixed when copied but move with structural row changes. Removed references become #REF!. Cached formula values are removed so the opening application recalculates. Cross-sheet/external references and compressed repeated rows/cells with formulas are rejected. This is reference rewriting, not an ODS calculation engine.

Dynamic category charts

await render(template, data, {
  charts: {
    'word/charts/chart1.xml': {
      categories: ['January', 'February'],
      series: [{name: 'Revenue', values: [120, 150]}]
    }
  }
});

DOCX, XLSX and PPTX chart parts support a single bar, line, area or pie chart with literal data and an existing prototype series. Series names, categories and values are replaced; chart layout and series styling are retained. Point-specific formatting/labels are removed because indices may change. Pie charts accept one series. Limits: 32 charts, 100 series, 10,000 categories and the XML byte budget. Workbook-linked charts, formula references, pivots, combination/scatter charts and embedded workbook synchronization are outside this adapter and fail explicitly. A standard Office-authored chart may therefore need a literal-data template before this API can update it.
