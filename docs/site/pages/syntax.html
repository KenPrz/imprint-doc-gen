Template authoring

One template language.

Use {d.path} everywhere. Formatting runs can split a tag without changing its meaning.

Fields and missing data

Template Meaning
{d.customer.name} A root or nested field.
{d.total:currency("USD")} Locale-aware currency text.
{d.name:required()} Error if missing, null or empty.
{d.name:default("Guest"):upper()} Ordered formatter chain.

Missing and null values become blank. Zero and false remain meaningful. Whole-cell XLSX/ODS values retain number and boolean types; mixed text produces a string. Data is never evaluated as JavaScript or recursively interpreted as template code.

Repeating blocks

Pattern row: {d.items[i].name}    {d.items[i].price}
Marker row:  {d.items[i+1].name}

The pattern repeats for each object. The marker is discarded. A multi-row block starts at the first pattern field and ends immediately before the marker. Marker fields must all refer to the same increment. Root fields keep their root meaning inside repeats. Empty, missing or null lists remove the region.

DOCX supports sibling rows, paragraph blocks and nested object lists such as {d.groups[i].items[i].name}. XLSX supports contiguous multi-row blocks, but not nested or horizontal repeats. PPTX supports paragraph/table-row repeats and whole-slide repeats followed by a marker-only slide. ODT/ODS repeat table rows; ODP can repeat whole pages.

Formatter reference

Formatter Example / behavior
number(2) Two fraction digits, locale grouping.
currency("USD") ISO currency code, locale formatting.
date("medium") short, medium, long, full or iso. ISO date input; timestamp inputs require an offset.
dateSerial("1900") Spreadsheet numeric date; select 1900 or 1904 explicitly and style the cell in the template.
upper(), lower() Locale-aware text case.
default("Guest") Fallback for missing/null/empty values.
if("Yes","No") Conditional scalar output using value truthiness. Does not remove document structure.
required() Require a nonempty value.

Set locale and timeZone on the request or SDK options. Defaults are en-US and UTC; concurrent renders have separate settings. A formatter chain has at most 16 operations and an expression at most 2,048 characters.

Filter repeated data

{d.items:where("active",true)[i].name}
{d.items[i+1].name}

{d.items:where("price","gte",100)[i].name}

Filtering precedes the iterator. Operators: eq, ne, gt, gte, lt, lte and contains. Arguments are JSON scalar literals. Nested calls, arbitrary code, prototype access and dynamic expressions are rejected.

Inspect and preview

npm run inspect -- template.docx
GOTENBERG_URL=http://localhost:3000 npm run preview -- template.docx data.json preview.pdf

POST /v1/inspect reports fields, required flags, package parts and paragraph/cell locations. POST /v1/preview accepts the render body and returns an inline PDF. Inspection validates recognized syntax and compilation; successful inspection does not guarantee that every runtime data shape will render.

Earlier double-brace bindings remain supported in DOCX/XLSX. Use the standard syntax for new templates and avoid mixing repeat dialects within a story or worksheet.
