API and SDK

Use synchronous rendering for immediate results, or immutable templates and durable jobs for background work.

Authentication and tenancy

Every endpoint except health/readiness requires Authorization: Bearer KEY. The environment API key is an administrator for the default tenant. Create a dedicated tenant and use its returned key in your application. Keys are returned only when created or rotated; stored keys are hashed. Admin access does not bypass another tenant's document ownership.

Method / path Purpose / request
GET /health · GET /ready Liveness; readiness checks configured storage and converter.
GET /metrics Admin-only Prometheus metrics.
POST /v1/render Base64 template, data, optional attachments/images/locale/timeZone/restartNumbering/charts/output. Binary result.
POST /v1/inspect {"template":"BASE64"}. Fields and diagnostics.
POST /v1/preview Render body; inline PDF response.
GET · POST /v1/tenants Admin list/create. Create body: {"name":"Example"}.
POST · DELETE /v1/tenants/:id/key Admin rotate/revoke tenant key.
GET · POST /v1/templates List/upload. Upload: {"name":"Invoice","template":"BASE64"}.
GET · DELETE /v1/templates/:id Metadata/versions or delete an unused template.
POST /v1/templates/:id/versions Upload a new immutable version: {"template":"BASE64"}.
POST /v1/templates/:id/publish Select current version: {"versionId":"ID"}. Also supports rollback to an earlier version.
POST /v1/jobs templateId, optional versionId, data and render options. HTTP 202 with job ID.
GET · DELETE /v1/jobs/:id Poll state or delete a terminal job.
GET /v1/jobs/:id/result Download successful output.
POST /v1/pdf · /v1/pdf/split PDF assembly and splitting.
POST /v1/barcode Barcode PNG.

Template/job routes require configured persistence. The one-shot POST /render/template?download=true route accepts template, data, attachments, images, locale, timeZone and convertTo; it returns the same binary output.

Reliable job submission

POST /v1/jobs
Idempotency-Key: invoice-2026-0001

{
  "templateId":"TEMPLATE_ID",
  "data":{"customer":{"name":"Example Company"}},
  "output":"pdf",
  "locale":"en-US",
  "timeZone":"UTC"
}

The job pins the selected version at acceptance. Reusing a key with the same serialized request returns the original job; changed data yields 409. States are queued, running, succeeded and failed. At most two attempts run for retryable worker/conversion failures; template/data errors do not retry. Completed jobs expire after seven days. Delete terminal jobs before deleting their template.

Errors

Status Meaning
400 / 401 / 403 Invalid request / invalid key / admin permission required.
404 / 409 Not owned or absent / state or idempotency conflict.
413 / 422 Resource budget exceeded / unsupported template, expression or data.
502 / 503 / 504 Storage/converter failure / admission or queue full / deadline exceeded.

Responses expose stable error codes and may include a package part. Do not retry 422 blindly. For 503, apply bounded backoff and honor Retry-After. Maximum JSON request size is 16 MiB including base64 overhead.

TypeScript SDK

import { readFile } from 'node:fs/promises';
import { compile, inspectTemplate, barcode } from './dist/index.js';

const template = await compile(await readFile('invoice.docx'));
const qr = await barcode({type:'qrcode', text:'invoice-123'});
const document = await template.render(
  {customer:{name:'Example Company'}, logo:'qr'},
  {attachments:{qr}, images:{qr:{fit:'contain'}}, locale:'en-US'}
);
console.log(await inspectTemplate(await readFile('invoice.docx')));

The SDK preserves the input document format and runs in the calling process. Use HTTP for worker isolation and bundled PDF conversion. Compile once and reuse for concurrent renders. This repository is private; no public npm publication is implied.

CSV/TXT templates use encodeTextTemplate before base64 upload. See expanded feature examples for text exports, chart data and numbering options.
