Support contract

Know what your template can do.

Six editable output formats, one syntax, explicit boundaries.

Format Supported structures Current limits
DOCX Split runs, bodies, tables, headers/footers, root fields in notes/comments; repeated rows/paragraphs, nested scopes, item images; preserved numbering definitions. Repeated note/comment references and numbering restarts need dedicated adapters. No tracked-change, vertical-merge, VML/OLE or strict-OOXML support.
XLSX Shared/rich strings, typed cells, multi-row blocks, contained merged ranges, per-item pictures, formula/range updates and bounded calculation. No nested/horizontal repeats, charts/pivots intersecting edits, shared/array/dynamic formulas or general Excel calculation.
PPTX Split runs, paragraph/table repeats, slide repeats, pictures, master/layout fields and cloned speaker notes. Custom slide shows/sections rejected. Internal slide links target the first generated copy; links to removed markers fail. Dynamic chart data is not implemented.
ODT Text/styles, table-row and paragraph repeats, frame pictures, manifest updates. Repeated XML IDs rejected; scripts/encryption/signatures/external assets rejected.
ODS Text and native number/boolean cells, repeated rows and frame pictures. Formulas inside repeated rows rejected because reference rewriting is not implemented. Static formulas are preserved.
ODP Text frames, pictures, repeated pages, master/style text fields. Same ODF package and ID restrictions; dynamic charts and embedded-object editing are outside this release.

Spreadsheet calculations

XLSX repeats update row addresses, A1 formulas, tables, filters, names, validation and conditional-format ranges. Formula copies respect relative rows and dollar locks. Deleted references become #REF!. Supported functions are SUM, MIN, MAX, AVERAGE, COUNT, IF, IFERROR, ABS, ROUND, ROUNDUP, ROUNDDOWN, LEN, LOWER, UPPER, CONCAT, AND, OR and NOT. Calculation is bounded by depth and operation limits. Unsupported formulas fail when recalculation is needed; unchanged workbooks preserve existing formula caches and request application recalculation.

PDF conversion

All six document types can be converted through the bundled LibreOffice service. Conversion is bounded and does not imply universal layout fidelity. A known DOCX stress fixture (level 93) stalls in LibreOffice; the converter is recycled after every attempt so later documents can proceed. Timeout returns HTTP 504, never a successful empty result.

What the corpora prove

The original 100 DOCX and 100 XLSX levels have independent expected outputs and structural scoring. Four additional 100-case corpora vary text, Unicode, split runs, styles, images and repeat counts. They are adapter regression suites, not full format specifications. Twelve selected new-format cases also compare PDF text with independently generated expected documents. Package/text agreement does not prove pixel fidelity, full schema conformance or repair-free opening in every Office application.
