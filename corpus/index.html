Imprint Doc Gen document test corpus

100 DOCX levels and 100 XLSX levels. Each level includes a template, JSON input and a reference output. Templates use standard {d.path} and [i]/[i+1] bindings. Ten cumulative bands increase structural and packaging complexity.

These are test fixtures, not engine results. Reference documents are generated by the fixture builders. Engine execution, full schema checks and Office visual approval remain separate gates.
